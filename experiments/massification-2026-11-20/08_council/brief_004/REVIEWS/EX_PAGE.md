# REVIEW — PAGE composite (drawing on Page 2018; Miller & Page 2007) — brief_004

**G. GROUNDING.** Literature basis: models are instruments; a result is a property of a model class unless
invariance is shown; identification is a property of the *contrast*, not of the fit. **COUNCIL EXTRAPOLATION:** the
loop assessment is the composite's.

**M. MODEL RENDERING.** Treat iteration 2 as a model-selection problem: M1 candidate class = {surplus/floor, Yoo
cutoff, competitive CES, outside-set}; M2 data = a moment vector m (country cards → targets); M3 fit criterion and
M4 a *predeclared* mapping from moments to rival-specific predictions; M5 the loop's claim is "the class is
identified by m"; M6 falsifier: two rivals fit the same m equally well while predicting the holdout differently;
M7 KIDS description of the cases before the fit. The design document is the *estimand specification*; without the
rival-prediction map it is a curve-fitting protocol.

**A. VERDICTS ON THE DESIGN (a).** Sound in architecture, **fit-first in sequencing**. The loop puts calibration (C)
before falsification (D) and the Council gate (E) last. C1 is decisive here: on six aggregate moments the two central
worlds are equidistant (0.012–0.023), and an outside-set truth is forced into the surplus world 2/2. If iteration 2
adds moments and calibrates before it declares which moments are *checks*, the loop will find "identification" by
construction. Amendment: move a design gate before C (this brief), and put the moment-to-rival prediction table in B
with the target set, not after the fit. The "change one variable per iteration" rule is right — but define *variable*
as a structural rule, not a value (see CARTWRIGHT).

**B. IMPOSED VS DISCOVERED (b).** C2's supplied-attainment result is the load-bearing diagnosis: schooling rises
because schedules rise; jobs rise with schooling frozen. The two-way requirement in §3 of the loop doc is the correct
response, but as written it can be satisfied by *two schedules interacting*. The test of whether it is a model is the
symmetric freeze: freeze schooling (test economy→?) and freeze wages/jobs (test education→?). If both sides survive
both freezes as schedules, the two-way is nominal. C1 then says: no amount of extra simulation of the same rivals
separates them; only new moments with *different predictions* can. So iteration 2 must (i) add moments that are not
in both worlds' fit sets, (ii) predeclare the sign pattern each world predicts for each new moment, (iii) carry a
truth-outside-the-set case each round, (iv) report an identification-gain metric (confusion-matrix improvement /
forced-identification rate). Otherwise it is re-parameterisation with extra data.

**C. ESTIMAND.** The loop's unit of evidence is the contrast between worlds on held-out moments, not a calibration
fit. State the estimand per stage: cards = measurement; targets = fit-vs-check declaration; calibration = residuals;
falsification = confusion matrix + holdout error; Council = claims audit.

**D. TYPE.** A calibration table is a *description of the model*, not evidence about a country. The loop doc already
says this; keep it in the stage definitions.

**E. STRONGEST DEFENSIBLE SENTENCE.** "The loop is a sound inference machine only if the discriminating moments are
declared before calibration; on the iteration-1 moment set the central worlds are not separated, and iteration 2 must
show an identification gain or drop the mechanism claim."

**F. NEGATIVE.** C1's forced identification is the most important result in the package: an outside-set truth was
assigned to the surplus world with confidence. Every future iteration needs that test — it is the cheapest guard
against the whole programme becoming a fitting exercise.

**G2. STEEL-MAN.** The strongest defence of the loop: new country data (provider composition, stage-specific
tutoring incidence, formal-access responses) genuinely are new moments that neither world was fitted to; if the
country cards deliver them, identification can improve. The design is right to bet on data, not on simulation.

**H. ALTERNATIVE.** If the new moments are themselves model outputs (simulated cards), identification cannot improve;
that is the failure mode to pre-empt: every target moment must carry a real-data source, or be marked simulated-only.

**I. WHAT WOULD CHANGE MY MIND.** An identification-gain table showing the confusion matrix improves and the
forced-ID rate falls when the new moments are added.
