# REVIEW — CARTWRIGHT composite (drawing on Cartwright 1999; Cartwright & Hardie 2012) — brief_004

**G. GROUNDING.** Literature basis: capacities are local; a model is not a law; evidence must match the structure of
the policy/claim; scope conditions must be explicit. **COUNCIL EXTRAPOLATION:** the stop-rule audit is the
composite's.

**M. MODEL RENDERING.** For each stop rule ask: what observable would show the capacity failing, at what precision,
and would the author accept it? M1 capacities in play: supplied schooling (C2), a one-way economy, endogenous shadow
demand (proposed), two-way feedback (proposed). M2 stop rules must be *predeclared, dated and hashed* before results.
M3 scope conditions explicit per claim. M4 model implication vs world claim. M5 nesting of rival worlds. M6 what
would make the programme stop. M7 KIDS: case description before calibration.

**A. VERDICTS.** The stopping criteria in §5 of `RESEARCH_LOOP.md` are the best in the programme: five rules, the
last of which ("the target was coded as a parameter") is exactly the anti-re-parameterisation criterion. But four
rules are missing and the loop should not run without them:
**(6) Out-of-sample miss:** if the held-out period/country error exceeds a predeclared margin, no country claim.
**(7) Unmeasured-parameter sign instability:** for any claim that depends on an unestimated parameter — the school-
support/commercial-tutoring substitution elasticity is the live case — if the sign flips over the plausible parameter
range, the claim is withdrawn, not hedged. E18/E18b already show this.
**(8) Institutional-parameter audit:** if fitting a country requires hand-set reader/floor rules that differ by
country, the result is a description of those rules, not a mechanism; label it.
**(9) Iteration budget:** the loop changes one structural variable per iteration; if two consecutive iterations
produce no identification gain (C1-style), stop claiming the mechanism and publish the equivalence/negative map.
Also: define "change one variable" as a **structural rule change**, not a parameter value change; otherwise the loop
is re-parameterisation with a nicer name.

**B. IMPOSED VS GENERATED.** C2's result is the model's honest self-description: schooling is supplied. The
two-way requirement must pass the symmetric freeze (schooling frozen; wages/jobs frozen). A model that only replaces
one direction with a behavioural rule does not have a two-way economy; it has a one-way economy pointed the other
way.

**C. ESTIMAND.** Each stage's publishable claim must be stated with its unit, scope condition, and the observation
that would refute it. The stop rules are the estimand specification of the loop.

**D. TYPE.** Publishable stages: (A) country cards = data descriptor; (B) targets = measurement note; (C) calibration
= model description with residuals; (D) falsification = identification/negative-results paper (the real product);
(E) Council = internal audit, not a publication. The whole loop = methods + negative map, which is publishable now
and is the most defensible output.

**E. STRONGEST DEFENSIBLE SENTENCE.** "The loop stops claiming a mechanism when the predeclared observables fail; the
programme's publishable product is the executed cells and the identification map, not a country finding."

**F. NEGATIVE.** The loop's weakest point is that "council review" is placed last: a council that only sees finished
runs can audit claims but cannot prevent a design from manufacturing them. Put the design gate before calibration
(this brief does that for iteration 2) and make the gate binding on the target-set labels.

**G2. STEEL-MAN.** The best defence: the loop already has the two elements most programmes lack — predeclared
comparisons and disclosed misses. With rules (6)–(9) added, it becomes a genuine falsification programme.

**H. ALTERNATIVE.** If the moment set cannot be extended with real data (HK blocked, PSA/DepEd 403), the honest
outcome is an equivalence result plus a data agenda; that is a contribution, not a failure.

**I. WHAT WOULD CHANGE MY MIND.** A dated, hashed stop-rule register; a disclosed out-of-sample miss; a sign-flip
withdrawal executed in writing.
