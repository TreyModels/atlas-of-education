## Where the panel disagrees

**D1. PAGE vs CARTWRIGHT — is "imposed by the equations" a defect?**
PAGE: no — model-class invariants are the legitimate product of model-based reasoning; the right response is an
ensemble, not an apology. CARTWRIGHT: an invariant across a model class is still a statement about models; a world
claim needs a scope condition and an observation. *What turns on it:* whether October may print "finds/establishes"
for C2. *Settles it:* a 3×2 ensemble (allocation × wage formation). Panel resolution: call C2 a model-class theorem,
never a discovery; ensemble it in the next batch.

**D2. PATRINOS vs COLLINS — what is novel?**
PATRINOS: only C3 could be novel, and it is not yet a fair test, so fix the test before writing novelty claims.
COLLINS: C3 is a queue property; the novum is the floor-as-eligibility object with many readers and dates, plus the
decomposition. *What turns on it:* the paper's framing and target journal. *Settles it:* E1 (matched rival) for
PATRINOS; E3 (allocation knockout) for COLLINS. Panel resolution: novelty = decomposition + many-floors institutional
claim; C2/C5 are restatements.

**D3. BRAY vs the brief's gate framing.**
BRAY: the model's basic-diploma tutoring share (0.05) is probably wrong for Cambodia/Philippines, where basic-level
tutoring is a mass market; the model omits teacher-tutors and the school-quality gradient, which are the mechanisms
the comparative record emphasizes. PAGE: that is a KIDS failure — the tutoring market is not described before it is
modeled. *Settles it:* a teacher-tutor/supplier arm, and observed gate-specific shares. The brief's own Double
Reduction note (demand re-routed, not eliminated) supports BRAY's prior.

**D4. On the ranked/lottery contrast.**
PATRINOS and CARTWRIGHT: the estimand changes meaning between arms (income return vs positional probability), so the
contrast is not a clean experiment; PAGE: that is fine if reported as class comparison; none of the three would let
the sentence "ranking causes intensification" stand unqualified.

**D5. Citation visibility (Q6).**
Unanimous: make C6–C8 *visible* — a "Prior work and what is new" subsection citing Yoo (2003) and Kim (2007); C6
and C7 stated as audit findings; C8 flagged as unverified citation, not asserted as a conflation; the 68-row register
and the correction log given to Bjørn. COLLINS: burying a known duplication is how credential-sociology papers get
rejected. CARTWRIGHT: the report's integrity is itself an object of evaluation.
