# REVIEW — PAGE composite (drawing on Page 2018; Miller & Page 2007) — brief_003

**G. GROUNDING.** Literature basis: results should be reported as properties of model classes, with invariance stated
and the class bounded by descriptive case knowledge. **COUNCIL EXTRAPOLATION:** the F5/F6 assessment is the
composite's.

**M. MODEL RENDERING.** The floor/race question is a model-class question: M1 allocation = {full rank, cutoff,
lottery}; M2 floor ∈ {none, adaptive, fixed}; M3 households with income-only utility and liquidity; M4 estimand =
slope of Q3–5 college entry on degree income across demand scales; M5 the paper's decomposition is the claim that
floor and rank are separable capacities; M6 falsifier: a non-rank allocation that preserves the negative slope. For
massification: M1' entry path = exogenous (supplied) or generated by household returns; M2' cohort accounting;
M4' observed entry path 1980–2020. If the generated path does not reproduce the observed rise, the model is
conditional, not generative.

**A. VERDICTS.** F5 **CONDITIONAL, and still the strongest plank** — but restated. At 4 reps: the floor's own
persistence contribution is at seed noise (|Δ| ≤ 0.002); ranked slopes −0.039/−0.064/−0.049; unranked +0.151/+0.036/
+0.630. The *movement* result survives: the adaptive floor's slope (−0.064) is steeper than the fixed floor's
(−0.049), i.e. floor movement, not floor level, adds intensification. The allocation knockout is **mixed**: rank+cutoff
−0.064, rank-only −0.039, cutoff+random +0.036 (n.s.), lottery +0.151; the predeclared "any non-rank allocation flips
the sign" threshold was **not** met. So the defensible decomposition is "floor level ≈ noise; floor movement + rank
ordering drive intensification"; it is not "any non-rank allocation removes it". F6 **FORCES WITHDRAWAL of the
trajectory claim.** In B4, EXO entry rises 0.22→0.55 as supplied; ENDO entry is 0.404→0.020 with large dispersion
(sd 0.384 at year 20) and ENDO_SMOOTH 0.218→0.108. The model does not generate massification; it requires a supplied
trend. Therefore any 10/20/30/40-year projection, "emergent massification", or "the model reproduces the rise" claim
must be withdrawn. What remains is a mechanism-conditional statement: given a supplied expansion path, the allocation
and floor rules determine who is included, excluded and invested in.

**B. WHAT IS IMPOSED.** F6 is the load-bearing negative: a household-only model has no reason to produce sustained
entry growth. B4's EXO path is an input; the ENDO path is unstable, so the instability itself must be reported, not
just the failure to rise. F5's sign is imposed by the allocation rule; the *decomposition* is the discovered part.

**C. ESTIMAND.** Slopes are comparative statics; the long-run experiment is accounting conditional on an input path.
Neither is a forecast.

**D. TYPE.** Both are simulation; the summary labels them so. Keep "supplied trend" in the same sentence as any
trajectory mention.

**E. STRONGEST DEFENSIBLE SENTENCE.** "The floor's level contributes no separately identified persistence; its
movement and the presence of rank ordering carry intensification, though only the lottery-versus-rank contrast is
identified at current precision; long-run massification requires a supplied expansion path, so the model's
trajectories are conditional accounting, not forecasts."

**F. NEGATIVE.** B4's ENDO instability (sd 0.384) is a stronger negative than "it does not rise": the generated path
is not even well-behaved, which means no trajectory claim can rest on it.

**G2. STEEL-MAN.** The strongest rival reading is that massification is an exogenous political/supply process
(Paglayan, world culture) and the model should be given that trend, not pretend to generate it — which is what B4
shows. This is a point in the rival's favour; say so.

**H. ALTERNATIVE.** Add a state/provider supply rule (public seats expand with demand) and a belief channel; the
ENDO path might then be stable. Runnable; not run.

**I. WHAT WOULD CHANGE MY MIND.** A generated entry path that reaches observed levels without an input trend, with
bounded dispersion; or an explicit decomposition showing the observed path is itself input-driven.
