## 0. Protocol binding on all three experiments

| Rule | Commitment |
|---|---|
| Language | Python 3.10 **standard library only**. `numpy` is installed on the host but **not imported** by the model (`grep`-checkable); all arithmetic is `random`, `math`, `statistics`. |
| Seeds | **200 seeds per cell** for every experiment (spec floor is ≥100; ≥200 where cheap, and it is cheap here). Seed list `20261120 + k`, `k = 0…199`. |
| Pairing | For a given seed, **every arm sees byte-identical latent draws**. Draws are generated by a per-`(seed, cohort)` `random.Random` whose construction never depends on the arm. Verified by a selftest that reconstructs the draw block twice and compares arrays element-wise, and by a selftest that runs arm A to completion *before* arm B and checks the draw block is unchanged. |
| Matched starting conditions | All arms of an experiment start from the *same* initial state vector (same initial seats / teacher and room stock / no-law baseline), the same `N`, and the same seed list. Starting state is printed into `RUN_MANIFEST.json`. |
| One-factor shocks | Exactly one imposed parameter changes per arm. Arms differ **only** in the declared factor; no arm changes two parameters, and no arm changes the latent draws. |
| Aggregation | Per-seed statistic → across-seed mean. Contrasts are **paired within seed** (arm minus its reference on the same seed). 95% CI = mean ± 1.96·sd/√n over the paired per-seed differences (normal approximation; n=200). `sign_share` = share of seeds whose paired difference has the sign of the mean. |
| Units | A cohort is `N = 120` children. Counts are children. Shares are reported in **percentage points (pp)** = 100·count/120, so 1 child = 0.833 pp. |
| Thresholds | Written here first, implemented as constants in `code/cluster_c_model.py`, evaluated mechanically by `code/run_cluster_c.py`. **No threshold is edited after the run.** If an edit were ever required it would be logged in §6 with a timestamp *and the run re-executed from scratch*, and the edit would be labelled post-hoc. |
| Reporting | **All** cells are written to `RESULTS.csv`, including null, wrong-signed, censored and failed cells. Verdicts are `PASS` / `FAIL` / `INCONCLUSIVE` with the reason. Failures are not suppressed or re-rolled. |
| Labelling | The string `ILLUSTRATIVE TOY — stipulated parameters; not calibrated; not evidence` appears in `RESULTS.csv` (column `label`), `FINDINGS.md` (header), `RUN_MANIFEST.json` (`label`) and the stdout banner. |

**Floor / ceiling definitions (fixed now).** `floor` = primary completion (level 0, bottom of the chain);
`middle` = secondary completion (level 1, upper-secondary); `ceiling` = tertiary completion (level 2, top of the
chain). "Universalization" = completion share ≥ **0.90** of the cohort at some cohort ≤ 30. "Censored" = the share
never reaches the bar within the 30 observed cohorts and is recorded as `>30`, never as a number.

## 1. Experiment 7 — Capacity by level (floor/ceiling split)

**Question (spec #7).** Can capacity alone universalize the ceiling, or only move the floor?

**Model change (spec: `takeoff.py` capacity shock at primary only / secondary only / tertiary only / all levels).**
A three-level sequential toy. Level `k` has `seats_k(t)` places and a two-part gate:

```
apply at level k  iff  cash_i >= fee_k  AND  ready_ik + 0.15*aptitude_i + 0.15*stock_k(t) >= gate_k
admitted_k(t)     =  first seats_k(t) eligible applicants in the cohort lottery order
completions_k(t)  =  admitted_k(t)                (a seat that is used is a completion; no dropout term)
```

`stock_k` is a stated community-readiness state (`0.8*stock_k + 0.2*completion_rate_k`, init 0.0) that lets past
completions pull future demand — this is what makes the arms dynamic rather than a one-shot urn, and it is
arm-dependent *state*, not arm-dependent *draws*. Capacity is installed with a four-cohort ramp:
`seats_k(t) = round(BASE_k * (1 + (m_k - 1) * min(1, t/4)))`, `t = 0…29`, where `m_k` is the arm's multiplier.

**Imposed parameter vector (stipulated, not calibrated):**

| Symbol | Value |
|---|---|
| `N` (cohort size) | 120 |
| cohorts `T` | 30 |
| `FEE` per level | (0.20, 0.36, 0.55) |
| `BASE_SEATS` (primary, secondary, tertiary) | (55, 20, 7) |
| `GATE` (readiness threshold per level) | (0.30, 0.45, 0.35) |
| `APT_W` (aptitude weight in the gate) | 0.15 |
| `STOCK_W` (readiness-state weight in the gate) | 0.15 |
| `CASH` group base + draw | (0.24, 0.62, 1.05) + U(0, 0.50) |
| capacity shock | **level capacity doubled** (`m_k = 2`), phased in over cohorts 1–4 (25 % per cohort), permanent afterwards |
| latent draws per (seed, cohort) | 120 × (cash, aptitude, ready_0, ready_1, ready_2) + lottery permutation |

**Arms (4 + control = 5):** `control` (m = 1,1,1); `primary_only` (2,1,1); `secondary_only` (1,2,1);
`tertiary_only` (1,1,2); `all_levels` (2,2,2).

**Estimands.** At cohort 30: seats, applications, admissions/completions **per level**, seat utilization
(completions/seats, the saturation marker), floor/middle/ceiling shares in pp, the floor−ceiling gap, and the
ceiling/floor ratio. Crossing years per level at the 0.25, 0.50 and 0.90 bars, plus the crossing order.

**Binding precondition (declared now).** An arm's own-level capacity claim is only evaluated for a level whose
*control* utilization at cohort 30 is ≥ **0.75**. If a level's seats are not binding, its own-level gain is reported
as `FAIL-NONBINDING` — informative (capacity without demand does nothing), not a model failure. Utilization is
reported for every cell so this is auditable.

**Thresholds.**

- **T7a (floor moves).** `primary_only` raises floor completion by **≥ +10.0 pp** vs `control` at cohort 30, paired,
  95 % CI excluding 0.
- **T7b (a ceiling-level shock moves the ceiling).** `tertiary_only` raises ceiling completion by **≥ +2.0 pp**,
  95 % CI excluding 0.
- **T7c (own-level conversion saturates).** `secondary_only` raises middle completion by **≥ +3.0 pp** but by
  **< 50 % of the imposed added-seat share** (doubling 20 seats adds 16.7 pp of seats, so the declared ceiling on
  conversion is **< +8.3 pp**). Both parts must hold.
- **T7d (floor/ceiling split, stated quantitatively).** In `primary_only`: ceiling gain **≤ +2.0 pp** *and*
  ceiling gain **≤ 0.25 × floor gain**.
- **T7e (no ceiling universalization from capacity).** No arm reaches ceiling share ≥ 0.50 at any cohort ≤ 30, and
  no arm reaches the 0.90 universalization bar at **any** level.
- **T7f (crossing asymmetry).** In `primary_only` the floor crosses 0.50 within 30 cohorts while the ceiling 0.50
  crossing is censored (`>30`) in **every** arm. Censoring satisfies this criterion only when the floor crossing is
  observed; a censored floor does not.

**Falsifiers.** **F7:** in any single-level arm that itself moves the floor (that arm's floor gain ≥ +2.0 pp),
ceiling gain ≥ floor gain (pp); **or** any arm reaches ceiling universalization (≥ 0.90) → capacity alone
universalizes the top level → contradicts A10 and would reopen the capacity question. Either event makes the toy's
mechanism incompatible with the A10/R29 reading and is reported as such, not explained away. The applicability
condition (floor gain ≥ +2.0 pp) prevents the comparison from being a degenerate 0-vs-0 in arms that do not touch the
primary level at all; it was added in deviation #1 below, before the 200-seed run.

## 2. Experiment 8 — Enforcement × compulsory law

**Question (spec #8).** Does a compulsory-schooling law bind without enforcement? (PHL de jure vs de facto.)

**Model change (spec: `takeoff.py`, law 0/1 × enforcement e ∈ {0, .5, 1}, attendance/completion mapping).**
One cohort of 120 households, `L ∈ {0,1}` de jure law, `e ∈ {0, 0.5, 1}` enforcement intensity (**declared, not
measured**: it is the probability-weighted intensity of inspection and sanction, not an observed inspection rate).

```
reg_i   = 1 if reg_i^0 + L*(0.10 + e*0.30*s_i) >= 0.70                  (registration / on the register)
att_i   = 1 if a_i      + L*(0.010 + e*0.35*s_i) >= 0.55                (attendance)
comp_i  = 1 if att_i and (r_i + 0.02 + L*e*0.35*s_i) >= 0.60            (completion: attended + verified learning)
work_i  = w_i * (1 - 0.60*att_i)                                        (household work displaced by attendance)
```

`a_i` (base attendance propensity), `s_i` (exposure/susceptibility to inspection and sanction), `r_i` (learning
readiness), `w_i` (household work intensity), `reg_i^0` are independent U(0,1) latent draws, **identical across all
six cells for a given seed**. The `0.010` term is the stipulated *norm/announcement* effect of the statute itself, so
that "law with e=0 ≈ no-law" is a testable margin rather than an algebraic identity; `0.10` is the analogous
register-only effect (a paper law moves the register more than the classroom — the PHL de jure/de facto point).

**Imposed parameter vector:** `N=120`; attendance threshold `0.55`; completion threshold `0.60` with base `0.02`;
`delta_norm=0.010`; `delta_enf=0.35`; registration threshold `0.70`, `reg_norm=0.10`, `reg_enf=0.30`; work
retention `0.60`.

**Arms (6 cells):** `(L,e)` = `(0,0)` no-law reference, `(0,0.5)`, `(0,1)`, `(1,0)` paper law, `(1,0.5)`, `(1,1)`.

**Estimands.** Registration, attendance, completion (shares in pp and counts per 120), household work (mean units and
% of no-law). Enforcement without a law is a built-in null: `(0,0.5)` and `(0,1)` are expected to equal `(0,0)`
*exactly* under the stipulated mapping, and are reported as such.

**Thresholds** (gains are paired vs the `(0,0)` no-law reference):

- **T8a (paper law is inert in the classroom).** `(1,0)`: |attendance gain| **≤ 2.0 pp** *and* completion gain
  **≤ +1.0 pp**. (Equivalence band, declared a priori.)
- **T8b (enforced law binds).** `(1,1)`: attendance gain **≥ +10.0 pp** *and* completion gain **≥ +6.0 pp**.
- **T8c (enforcement gates the law).** Attendance gains are monotonically non-decreasing in `e` at `L=1`;
  gain(e=1) **≥ 4 ×** gain(e=0); and gain(e=1) − gain(e=0) **≥ +8.0 pp**.
- **T8d (mechanism-consistency diagnostic, not a test).** Household work falls only where attendance rises; declare
  the work reduction under `(1,1)` to be ≥ 3× that under `(1,0)`. Reported as a diagnostic.

**Falsifier.** **F8:** attendance gain at `(1,0)` **> 2.0 pp** → the law binds without enforcement → the enforcement
leg is redundant and the de jure/de facto story fails in the toy.

## 3. Experiment 9 — Buildings vs teachers at equal budget

**Question (spec #9).** Do physical seats without staff produce usable places?

**Model change (spec: Luna item 4 toy, equal budget for rooms-only, salaries-only, split; rural retention varied).**
One cohort, fixed budget `B = 480` units, spent as `rooms*12 + posts*60 = 480` in **every** arm (invariant asserted).
Stock is *matched* across arms: 30 existing physical places, 2 existing teacher posts.

```
physical_places = 30 + rooms_added
eff_teachers    = (2 + posts_added) * pi            pi in {0.60 low, 0.90 high}  (rural retention, declared)
teacher_capacity= eff_teachers * 12                 (12 places per teacher at full quality)
admissions      = min(physical_places, teacher_capacity, 120)   (all 120 apply; admissions = staffed places)
load            = admissions / eff_teachers
q               = 0.92 if load <= 12 else max(0.55, 0.92 - 0.04*(load-12))
completions     = first `admissions` children in lottery order with pass_i <= q
PTR_declared    = admissions / (2 + posts_added)     PTR_effective = admissions / eff_teachers
```

**Imposed parameter vector:** `N=120`; `B=480`; `room_cost=12`; `teacher_cost=60`; `teacher_capacity=12`;
base stock `(30 places, 2 posts)`; `pi ∈ {0.60, 0.90}`; `q_base=0.92`; `q_floor=0.55`; `q_slope=0.04`.

**Arms (3 × 2 = 6 cells):**

| Arm | rooms | posts | check |
|---|---|---|---|
| `rooms_only` | +40 (=480/12) | +0 | 40·12 = 480 |
| `teachers_only` | +0 | +8 (=480/60) | 8·60 = 480 |
| `split` | +20 | +4 | 20·12 + 4·60 = 480 |

crossed with `retention_low (pi=0.60)` and `retention_high (pi=0.90)`. Each retention level also carries a
`baseline` reference cell (status quo stock, no purchase) as the matched starting condition for that `pi`.

**Estimands.** Physical places, staffed places (= admissions), completions, PTR (declared and effective), and the
rooms-to-teacher composition. Applications are unconstrained by stipulation (all 120 apply), so admissions = staffed
places; this is stated rather than estimated.

**Thresholds.**

- **T9a (rooms without staff).** `rooms_only`: physical places **≥ +30** vs its baseline; staffed places gain
  **≤ +2**; completion gain **≤ +1.0 pp** — at both retention levels.
- **T9b (split dominates rooms at equal budget).** `split − rooms_only`: staffed places **≥ +20** *and* completion
  **≥ +5.0 pp**, at both retention levels.
- **T9c (composition, not just spend).** `split − teachers_only`: completion **≥ +3.0 pp** at both retention levels;
  and `teachers_only`'s completion gain over baseline is **≥ 30 % lower** than `split`'s.
- **T9d (retention binds only where teachers bind).** `split(high) − split(low)` completion **≥ +2.0 pp**, while
  `teachers_only(high) − teachers_only(low)` **≤ +2.0 pp** (rooms are the binding constraint there). Baseline and
  `rooms_only` are teacher-constrained, so their retention difference is expected ≥ +2.0 pp; reported, declared as a
  structural prediction of complementarity.

**Diagnostic (declared, not a test).** D9: `teachers_only` attains the **lowest** PTR of all arms while completing
fewer children than `split` — a measurement caution: a good PTR is not evidence of usable places.

**Falsifier.** **F9:** `rooms_only` completion gain **> +1.0 pp** → rooms alone produce completions → composition is
irrelevant in the toy.

## 4. What each outcome would and would not mean (fixed in advance)

- **PASS** on any threshold means: *this stipulated production function reproduces the predeclared pattern*. It is a
  property of the stipulated rules. It is **not** evidence about the Philippines, about massification, or about any
  historical episode.
- **FAIL** on a threshold is reported first, in full, in `FINDINGS.md`; it is a property of the stipulated rules too,
  and it does not reopen the phase in either direction.
- A **near-tautological** cell (one where the arithmetic forces the answer, e.g. rooms-only completion under a strict
  complementarity) is flagged as such in `FINDINGS.md` and excluded from any "support" language.
- No cell of this run may be described as "confirming", "showing", "estimating" or "calibrating" anything.
