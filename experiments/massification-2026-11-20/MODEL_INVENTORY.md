# MODEL INVENTORY — stocktake of code Trey already built

Audited 2026-11-20 by `repo-auditor`. Sources are read-only; runs are in `03_audit/runs/`.
Status column means **executed by this audit** ("smoke", "full run", "not run") — not a claim
about quality.

Two code bodies exist, and they are not the same repository:

- **A. `01_sources/massification_project/`** — the October paper's own models (`massabm`, `triad`)
  and every stored result round (rounds 1–8). **No VCS metadata**; a local snapshot only.
- **B. `01_sources/atlas-main-55732f4/`** — the public `TreyModels/atlas-of-education` worktree at
  verified commit `55732f4728a13adb3aec5173d8bc7f3a4ac7f926` (14 Nov 2026 revision). It contains the
  *engines* (`floorworld`, `childworld`, `relfloor`, `firms`, `shadow-abm`) and the **stored**
  massification web data, but **not** the `massabm`/`triad` source. Its own `research/ISSUES.md`
  records `related/massification_project` as absent.

## Manuscript claims with a code path that is NOT in the public atlas checkout

The public worktree contains the engines that the atlas **web page** uses, but the paper's own
`massabm`/`triad` source is absent there (`research/ISSUES.md` records `related/massification_project`
as missing; README says "No production experiment results accompany it"). The local
`01_sources/massification_project/` copy fills that gap for:

1. All `massabm` case-model results (6-arm floor/race table, graduate-supply shock, gate tutoring shares, K-12 distribution, fiscal ledger).
2. All `triad` results (actors' contributions, lock-in/dose, emergence timing, conditions, state motives).
3. The stored `public/research/massification/*.csv` web data: the *values* are present in the public tree but the **code that generated them is not** in the public tree.
4. The paper's own reproducibility claim ("[^code] … distributed with this paper … results from every round of runs") cannot be checked from the public repo alone; only this local copy makes it runnable.

The atlas engines (`floorworld`, `childworld`, `relfloor*`, `firms`, `tutoring_abm`) are present and
runnable in the public worktree, but **the paper cites almost none of their numbers**; they are
"repository audit leads" in `03_model_architecture.md`, not sources of the manuscript's tables.
