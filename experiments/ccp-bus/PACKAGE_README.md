# CCP bus model: handover package (19 November 2026)

Read `BRIEFING.md` first (two pages).

- `papers/`: *The Priest and the Bandit* manuscript, the original white paper, and the literature review.
- `models/A_claude_v1_three_models/`: three rival mechanism models, mean-field docking, experiments.
- `models/B_claude_v3_economy_factions/`: economy + sectors + factions model, ABC calibration, scenarios.
- `models/C_chatgpt_v6_tilly/`: 50,000-agent Tilly model, code, docs and summary results (raw run files omitted).
- `models/D_chatgpt_v7_identification/`: fitted rival families with the 2020–25 holdout test (complete).
- `data/`: verified official series (CCDI cases, land revenue, defense, credit, 2026 monitoring) with sources.
- `figures/`: ten figures from the Claude evaluation.

Python 3.11+, numpy, pandas, scipy, matplotlib. Each model folder runs on its own; see its README or SPEC.
Omitted for size: 828 v6 run files, earlier ZIP deliveries, the original archive (available on request).
