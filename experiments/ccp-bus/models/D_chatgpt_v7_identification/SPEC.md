# V7: identification, persistent feedback and temporal testing

Development specification, 18 November 2026, written before the following experiment. Earlier versions and data remain intact. This is a retrospective temporal holdout with previously seen outcomes, not a genuinely prospective forecast or a public preregistration.

The priority is discriminating mechanisms against observations. V6's expanded Tilly modules are retained as archived code, disabled in the primary comparison. No new direct obligation-to-misconduct or rank-to-misconduct terms are enabled. Numerical accounting and immutable person/case identities remain.

Three nested behavioral families use the same case-filing and sanction pipeline:

- current_incentives: current opportunities and an externally announced inspection-risk rule; no social complementarity, inherited patron advantage or endogenous reporting capture.
- social_trap: steep choice response, local strategic complementarity and peer-dependent reporting with finite investigation capacity, following the original many-model family.
- bus: social_trap plus person-bound contacts, incumbent sponsorship and office-contact inheritance through turnover. Sponsored integrity bias remains zero. Social affiliation is not itself classified as misconduct.

The response temperature 0.35 restores the original kernel's steeper choice response. Peer gain and reporting capture are estimated over ranges that include zero; no family is required to exhibit long memory. A model is allowed to lose predictive or memory tests. Social-trap and bus families receive the same parameter search and observation rules.

Calibration uses only filed-case observations for 2013–2019 and available pre-2020 economic inputs. Seven annual observations cannot identify all latent mechanisms. Fit a small parameter subset by simulated minimum distance; profile a single case-count scale on training data and save every candidate. Do not call accepted candidates a Bayesian posterior or estimate national corruption prevalence from these counts.

The shared investigator-capacity ramp and 2018 step are hypotheses about resource/coverage growth, with parameters estimated using training observations. No 2024 step is specified. The strict 2020–2025 forecast holds 2019 land receipts and enforcement rules fixed. A separate conditional hindcast uses realized land receipts, clearly labeled. No 2020–2025 cases, normalization constants or economic outcomes enter fitting or candidate selection. Retrospective information cutoff is after the 2019 annual releases in May 2020.

Use training-only normalization, identical targets, parameter bounds and search budgets. Validate candidate selection using additional training seeds before generating held-out predictions. Compare against last-value and log-linear trend benchmarks. Report forecast error alongside the fitted scale and the ensemble's latent-prevalence range to reveal weak identification.

Memory tests compare histories under identical present policy/resources. Measure paired future divergence over 10/30/60 years, not just return after deleting debt. Also test head replacement, clearing short-lived liabilities and reconstructing a common state. The current-incentive family supplies a behavioral null; differences in pending cases alone are observation memory. A full-state reset must eliminate history effects.

Run fitting at 12,500 total agents / 16 organizations and check selected fits at 50,000 / 64 organizations, preserving 625 official seats per organization and the rank proportions. Report changes in sector composition. Calibration and testing use civilian filings only; the national scale is an observation coefficient rather than a known population crosswalk.

The supplied archive contains the original memory/calibration code. A newer Opus implementation has not been provided, so this merges the available original mechanisms, rather than claiming access to an unseen model.
