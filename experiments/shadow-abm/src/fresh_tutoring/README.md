# Fresh-school experiments on the completed tutoring ABM

This extends the user's local completed run. It does not refit parameters. It draws 40 posterior particles with replacement according to each variant's stored weights and tests each on the same five new random world seeds (9,700,000–9,700,004), then compares baseline and own-pupil tutoring ban in each world. Across four variants this is 800 paired baseline/ban runs, or 1,600 model evaluations. Seeds differ from the provided calibration's seed-counter range. Results depend on the selected particles and the five fixed worlds.

## Files and reproducibility

Run from this directory: `python -m pip install numpy scipy pandas`, followed by `python run.py --particles 40 --worlds 5 --workers 4 --out results`. `results/draws.csv` has the per-pair results, `results/summary.csv` summarizes them. `source_results/posterior_*.json` are copied without modification from the attached completed run; model.py, smc.py and calibrate.py are copied from it. The random sampling seed and world seeds are fixed in run.py. The ban changes only the ban flag and baseline/ban use the same seed; random streams and teacher choices can still diverge when the solver branches.

A fit means all seven original targets are within their existing tolerance bands. It is an in-model reproduction of those aggregate moments in a new randomized model world, not a holdout against new real schools or independent data. A fit share measures outcomes among a resampled collection of previously selected parameter particles and five worlds, not evidence that a particular mechanism is true. Because 40 draws can repeat and each uses the same five worlds, 200 rows are not independent. Medians and percentiles summarize these choices; they are not confidence or credible intervals. Neither the particle sample nor world sample is large enough to rank variants.

The table records baseline convergence only. Non-converged baseline and ban solutions are not excluded; the model stops after its iteration cap. Fit patterns, ban effects, teacher strategic behavior, and quality measures inherit all assumptions and the calibration dataset of the input package. Ban results are hypothetical conditional on the model, not evidence of real-life policy effects. `nonbuyer_class_instruction` is the model's curriculum share metric and not direct evidence on learning or measured instruction; near-zero values reflect the chosen withholding mechanism and calibrated worlds. This study does not couple tutoring to household work or dropout.

The source package itself warns that the evidence calculation is too sparse for model selection, that parameter worlds often fail on new seeds, and that the four variants may reproduce the same limited patterns. This exercise does not resolve those issues; it repeats the fresh-world question using multiple common worlds per sampled particle.
