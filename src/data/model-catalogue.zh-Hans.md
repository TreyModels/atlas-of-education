## 如何使用本目录

每个条目都提出一个关于系统如何运作的主张，目标是将其变成图谱中可运行的模型。对同一结果的不同解释应使用同一批数据检验。

每个条目记录：

- **主张**：一句话说明要解释的结果。
- **机制**：用通俗语言写明因果规则。
- **方程或规则**：指出论文、附录或代码中的位置。
- **代码与数据**：记录公开材料及其许可。
- **拟合检验**：指定模型必须重现的观测规律。
- **竞争模型**：列出用不同方式解释同一结果的条目。

| 状态 | 含义 |
| --- | --- |
| 已上线 | 已是图谱中的可运行模型 |
| 待移植 | 有公开代码或数据，可改编 |
| 待实现 | 已发表方程，可据论文实现 |
| 叙述性 | 有数据论证但尚无形式模型，可尝试形式化 |
| 重型 | 已有模型，但需要 Dynare、MATLAB 或大型微观数据 |

## 中国经济增长的竞争机制

三个形式模型以不同原因解释投资增加、劳动收入份额下降、对外盈余扩大。用同一数据集评分可看出分歧。

| 模型 | 所提机制 | 状态 | 拟合检验 |
| --- | --- | --- | --- |
| [Song、Storesletten 与 Zilibotti，《像中国一样增长》（2011）](https://econpapers.repec.org/RePEc:aea:aecrev:v:101:y:2011:i:1:p:196-233) | 信贷摩擦。生产率高的私企自筹资金，生产率较低的企业依靠较易获得的信贷存续 | 待移植。AER 数据集和[作者代码](https://campuspress.yale.edu/zilibotti/published-research) | 资本回报持续、产出向私企转移、1992年以来的对外盈余 |
| [Chang、Chen、Waggoner 与 Zha，《中国宏观经济的趋势与周期》（2015）](https://www.nber.org/papers/w21244) | 重工业获得优惠信贷 | 重型。双部门 DSGE，可简化为信贷分配规则 | 投资与消费联动较弱、投资率上升、劳动收入份额下降 |
| [Bai、Hsieh 与 Song，《财政扩张的长期影响》（2016）](https://www.nber.org/papers/w22801) | 2009–10年刺激通过地方融资平台表外融资，惠及有关联的企业 | 待实现。将叙述形式化为土地抵押借款 | 2010年后投资持久上升，刺激后表外支出每年约占 GDP 的5% |

**共同评分数据**：1992–2024年投资率、劳动收入份额、经常账户以及私营与国有产出份额。Chang 等人提供的年度和季度宏观序列可作为共同数据集。

**待研究**：Isabella Weber 的双轨价格改革解释可能适用于1980年代的起步阶段，尚无形式模型。

## 中国信贷与房地产

信贷解释已有论证，尚未有公开的形式化模型。两项住房研究对房地产是危机触发因素还是放大因素有不同看法。

| 研究 | 论点 | 状态 |
| --- | --- | --- |
| [Logan Wright，《Broken China》（2026）](https://fsi.stanford.edu/node/39615) | 增长放缓源于金融体系和空前信贷扩张的结束。参见[《信贷与信用》（2018）](https://www.csis.org/analysis/credit-and-credibility-risks-chinas-economic-resilience) | 叙述性 |
| [Rogoff 与 Yang，《中国住房见顶》（2020）](https://www.nber.org/papers/w27697) | 房地产及相关行业约占 GDP 的29%，住房下行使产出累计减少5–10% | 待实现。适合浏览器的投入产出乘数 |
| [Fang、Gu、Xiong 与 Zhou，《解读中国住房繁荣》（2015）](https://www.nber.org/papers/w21112) | 房价随收入增长，超过35%的首付使住房成为放大因素 | 待实现。按购房队列设置房价收入比和杠杆规则 |
| [Tianlei Huang，《Detox》（待出版）](https://www.pulse.bot/real-estate/news/understanding-chinas-economy-and-the-housing-bust-with-tianlei-huang-aab32144-79af-4919-be93-176d6e7de292/) | 房地产下行迫使地方政府处理财政问题 | 叙述性 |

**拟建模型**：用存量流量一致框架连接家庭、开发商、地方融资平台、银行和中央政府。每笔贷款对应一项资产，各期资产负债表需平衡。可调变量包括土地出让依赖、预售融资、首付规则、信贷增长目标和银行宽限。检验家庭杠杆、2020年融资限制后的开发商违约时间和土地收入占地方预算的比重。

可用 Godley–Lavoie 框架及 R 的 `sfcr`、Steve Keen 的 Minsky 等开放实现。Rogoff–Yang 的投入产出关系可用来估算产出传导。

## 中国1999年高校扩招与青年失业

实证研究对扩招的就业影响有分歧。目录尚未找到青年失业的开放形式模型，图谱的毕业生队列是现有候选。

| 研究 | 发现 | 在图谱中的用途 |
| --- | --- | --- |
| [Knight、Deng 与 Li（2017）](https://econpapers.repec.org/RePEc:csa:wpaper:2016-04) | 1998–2008年招生近增至六倍，新进入者相对工资下降、失业上升、优质岗位减少，在职者受到保护 | 检验毕业生队列能否重现在职者保护 |
| [Ou 与 Zhao（2022）](https://econpapers.repec.org/RePEc:bla:chinae:v:30:y:2022:i:2:p:117-141) | 短期内男性和大学毕业生失业下降，女性参与率和高技能收入下降 | 竞争结果，利用省际差异和 Bartik 需求控制 |
| [Yu（2014）](https://dalspace.library.dal.ca/handle/10222/50406?show=full) | 年轻毕业生失业上升8.7%，全职就业下降21% | 竞争结果，使用 CHNS 数据 |
| [Li、Whalley 与 Xing（2014）](https://econpapers.repec.org/RePEc:iza:izadps:dp4974) | 扩招大幅提高入学机会，各群体增幅不同 | 补充队列的入学机会一侧 |

**数据口径**：16–24岁官方失业率自2023年调整为排除在校生，前后数据不可直接比较。旧口径2023年6月峰值为21.3%，新口径2026年8月为18.9%（[报道](https://www.qatar-tribune.com/article/255654/business/chinas-youth-unemployment-hits-record-high-as-ai-deepens-job-crunch)）。

**待加基准**：QuantEcon 的简单求职匹配“湖泊模型”只用就业转入率和离职率。检验 Tilly 分类能否额外解释7月峰值、劳动力之外的等待和在职者保护。

## 菲律宾的学习与辍学

Pritchett 的学习曲线模型使用中低收入国家数据校准。模型显示，普及十年级毕业带来的学习增量较小，放慢课程进度可增加约1.6年等效学习。这与增加两年学制的 K–12 改革直接相关。

| 研究 | 机制 | 状态 |
| --- | --- | --- |
| [Beatty 与 Pritchett，《课程目标过高的负面后果》（2012）](https://www.cesifo.org/DocDL/cesifo1_wp4040.pdf) | 教学难度与学生水平匹配时才有学习增量，课程推进过快会使学习曲线变平 | 待实现，论文提供方程 |
| [Kaffenberger 与 Pritchett，学习动态结构模型（2021）](https://pmc.ncbi.nlm.nih.gov/articles/PMC7994294) | 以观测到的学习轨迹校准潜在教学函数 | 待实现，开放论文提供参数 |
| [PIDS，高中与劳动力市场](https://pidswebs.pids.gov.ph/CDN/INFOCUS/pidsupdates79.html) | 基础教育中男生辍学或不及格人数较多 | 拟合目标 |
| [Etulle 与 Carmelotes，K–12辍学模拟（2014）](https://rmrj.usjr.edu.ph/rmrj/index.php/RMRJ/article/view/99) | 预测 K–12 期间89%辍学 | 预测缺乏可信度，不作为建模依据 |

**拟建模型**：结合图谱的重建队列与 Pritchett 教学函数，分别模拟谁继续上学以及每年学到多少。可调课程速度、补救教学和十至十一年级升学。目录引用的2018年数据给出18%的初中生未升入高中（[来源](https://portal.amelica.org/ameli/journal/725/7253717004/html/)）。输出学习调整受教育年限与学习贫困，并连接现有 LAYS 工具。

**待研究**：用哪套菲律宾评估数据按年级校准学习曲线，国内测验还是2018与2022年的 PISA？

## 待实现的经典发展模型

这些教科书模型有已知方程，预计各约一天，可作为国别模型的比较基准。

| 模型 | 机制 | 对应模块 |
| --- | --- | --- |
| 刘易斯二元经济 | 农村剩余劳动力以固定工资转向现代部门，直至达到转折点 | 中国和柬埔寨的劳动力供给、农村和金边工资 |
| Harris–Todaro 迁移 | 按预期城市工资迁移，因此新增岗位时城市失业也可能增加 | 柬埔寨迁移和毕业生队列 |
| [Doepke 与 Zilibotti，劳动标准与童工](https://campuspress.yale.edu/zilibotti/published-research) | 检验国际劳动标准是否延长童工现象 | 柬埔寨最低就业年龄执法 |
| Schelling 隔离 | 温和的邻里偏好也会产生强烈分化 | 择校与隔离教学示例 |
| 贫困陷阱 | 低于资本或营养阈值时，家庭难以靠投资脱困 | 柬埔寨家庭选择与债务减免 |
| Spence 信号与 Dore 文凭病 | 学历即使不增技能也可筛选劳动者，从而推高学历要求 | 学历门槛与毕业生队列 |

**待研究**：哪些机制适合主体模型，哪些适合闭式模型？候选分别包括 Schelling、异质迁移者的 Harris–Todaro，以及刘易斯和 Spence。

## 数据来源与现有模型库

图谱的方向是让用户在浏览器中用同一国别数据比较发展与教育的竞争机制。

| 资源 | 内容 | 用途 |
| --- | --- | --- |
| [Wittgenstein 人力资本数据](https://iiasa.ac.at/models-tools-data/wcde) | 约200国按年龄、性别与教育分组的人口，七种情景至2100年，旧版可回溯至1950年 | 中国、菲律宾、柬埔寨的共同数据基础 |
| [CoMSES 模型库](https://comses.net/resources/standards) | 超过1,100个具 ODD 文档的主体模型，多为 NetLogo | 移植候选与 ODD 文档标准 |
| [宏观经济模型数据库](https://www.macromodelbase.com/news-item/mmb-release-3-3) | 3.3版含161个结构宏观模型 | Dynare 重型模型及比较设计参考 |
| ReplicationWiki | 包括《像中国一样增长》的论文复现状态 | 移植代码前检查 |
| QuantEcon 课程 | 增长、求职和湖泊模型的开放 Python、Julia 代码 | 基准与教学模型 |

**许可**：引用已发表方程并自行实现。移植代码前核查许可，缺少许可时联系作者。
