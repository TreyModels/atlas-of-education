## 0. Framing (operator decision, 2026-11-25)

The manuscript's numbers are the **AUTHOR-REPORTED BASELINE**. Gemini ran the papers inside its app; we are not
recovering its files and there is no Codex Paper-A re-run to compare against. The **NEW GENERATION** is the
repaired-engine reimplementation (pre-registered, hashed, with uncertainty/baselines/sensitivity), reported
separately. These errata therefore use two labels throughout: **AUTHOR-REPORTED BASELINE** for the docx numbers and
**NEW GENERATION** for the repaired-engine runs. Nothing in the docx is to be silently replaced; the corrected table
shows both columns with the reason for each difference.

## 0. Required label convention (use on every table, figure and results paragraph)

Because the programme has three result generations, every numeric block must carry one of these labels:

* `[VERIFIED EMPIRICAL — committed record]`
* `[AUTHOR-REPORTED 420 generation — not reproduced]`
* `[REPRODUCED SIMULATION 540 pre-repair — not calibrated]`
* `[REPRODUCED SIMULATION 540 repaired — UNCALIBRATED, not validated]`
* `[UNRESOLVED — no committed artifact]`

A table that mixes generations is a defect in itself. Do not present a 420-generation table next to 540-generation
text without labels.

## 1. Banned-language list (global)

Delete or replace every occurrence of: **proves / proved / theorem / demonstrates / validates / confirms /
backfires / reproduces (a historical event) / directly explains / only (as a ranking claim) / calibrated
(unless followed by the record and generation) / exact same policy hierarchy / structural law**.

Replace with: *is consistent with / illustrates under this specification / in the author-reported 420 generation /
in the reproduced 540 generation (pre-repair) / in the repaired 540 generation (uncalibrated) / local rank / not
established*.
