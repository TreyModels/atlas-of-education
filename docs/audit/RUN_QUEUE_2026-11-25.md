## Shutdown protocol (safety-first)

1. Mac-side poller checks every 2 min for `/root/work/queue/RESULTS_DONE`.
2. On detection: pulls `paperC_screening_results.json` + all `ckpt_*.jsonl` + logs + SHA256SUMS into `~/neon-boot/qa/incoming/paperC_screening/`, verifies sha256, then touches `/root/work/queue/SHUTDOWN_OK` on the box.
3. Box finalizer sees the flag → `sync; shutdown -h now`.
4. **Failure path:** missing JSON, wrong row/cell count, or failed hash ⇒ finalizer writes `FAILED` and **exits without shutting down**; the box stays on for the operator.
5. If the Mac poller dies/session ends, no `SHUTDOWN_OK` is written ⇒ box stays on (safe default), finalizer logs `no shutdown signal`.
