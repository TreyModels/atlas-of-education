# Age-aligned survey tests: India and Kyrgyzstan

Generated by `python engine/childworld_agealigned.py`. Matching targets and test targets come from the same survey on the same age bands (inputs and links in `engine/data/asia_school_work.json`, `age_aligned`). Worlds are random draws from the priors (master seed 7, the same rule as `childworld_mc.py`, but a different number of draws, so not the same worlds); kept if within tolerance of every target. Predictions are medians with 10-90% ranges over kept worlds. A test passes if the observed value lies inside the 10-90% range.

## What this does and does not show

* The India test now uses one survey, one definition (economic activity only; chores excluded, so domestic care sits in "neither", which is what state D represents) and the same age bands for matching and testing.
* Kyrgyzstan cannot be tested as a point prediction from what was retrievable: the survey work concept is broader than the model's, the age bands follow school levels, and the 38.4% has no definition on the page that reports it.
* Unresolved items are listed in `data/asia_school_work.json` under `age_aligned.unresolved`.
