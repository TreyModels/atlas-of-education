# Corrected simulation code: mapping and limitations

**Exploratory simulation; not empirical evidence or a confirmatory test.** This mapping documents implementation choices absent from the preregistration at 77d6f23. The 0.05 raw-slope equivalence margin has not been substantively justified for each outcome. Outputs are not a basis for claiming that the macro wall holds in actual countries.

## Matrix

- `run_corrected.py`: four literature worlds and the s=0 common baseline (`null`), 25 years. The null retains baseline mechanisms; it is not a world without all mechanisms. The model and backend are unchanged copies of the earlier kernel.
- Full settings: 10,000 households, 64 simulated countries, 10 independently drawn blocks; smoke: 300 households, eight countries, two blocks. Country nuisance parameters are independently generated per block; within a block the same country characteristics are paired across worlds, and household randomness is independent across worlds. SHA-256 namespaced seeds produce repeatable independent streams.
- Four illustrative parameter archetypes are explicitly encoded in TYPES; countries are assigned by c modulo 4. The five grouping levels are the entire block and each of these four archetypes. They are synthetic categories, not measured real-world regions or the later proposed 80 groupings. Each subgroup has 16 countries in full, only two in smoke.
- GER is the regressor. Outcomes are shares child employment, study/work, work-only, hidden work, tutoring, mean learning, and mean household income. Model-specific units apply. This retains mean income and raw slopes; it does not implement the later proposed log-income or standardized-slope amendment.
- S1: 10-year differences and decade dummies; S2: 5-year differences and 5-year-bin dummies; S3: levels, country and year fixed effects; S4: S1 plus change in mean income; S5: S2 plus archetype indicators (for an individual archetype there is no varying indicator); S6: annual first differences. The income outcome in S4 is explicitly unestimable: adjusting an outcome for itself is meaningless. Failures and ranks are retained, never coerced to zero.
- Measurement error multiplies GER and the outcome by independent lognormal noise with log SD zero or 0.05. A separate deterministic stream is used for each block, country, world, link and specification. This is an explicit noise assumption, not a measurement-error estimate.
- Each within-block/world fit reports a country-cluster sandwich standard error and 90% and 95% intervals using conservative t quantiles. These are unreliable with very few clusters; smoke intervals are for mechanics only. Contrasts pair slopes by independently generated country block and use the variation of paired block differences for a 90% interval and provisional TOST. A missing fit is excluded and the number of usable blocks is reported. The preregistration's 0.05 raw-slope margin is retained for traceability only and cannot justify a confirmatory equivalence claim. No pooled share of 'equivalent cells' or binomial confidence interval is calculated. Multiple testing and outcome-specific margins remain unresolved.
- The script saves every fit and every pairwise comparison; it does not silently overwrite output files. It does not implement predictive classification. The terms 'null' and 'equivalence' refer only to these specified synthetic worlds and margin.

## Phase B

See `phaseb_corrected.py` and its companion upstream runner, if present. They use 4,000 women per full unit and report feature-specific denominators and missingness. B1 compares within-mother mean completed interbirth intervals with and without a death since the preceding birth, averaging only women with both types; this is a conditional, selected subset. B2 compares parity progression among women who reached parity one by education; B3 compares first-birth ages among observed mothers by education. These definitions and denominators are not validated against DHS.

## Verification and operation

`python3 -m unittest -v test_corrected.py` tests fresh seeds, reproducibility, genuine five-year windows, paired block inference, shared baseline and rank failure. `python3 run_corrected.py --smoke --workers 4 --output NEW_FILE.json` runs the reduced test. Use a fresh output path each time. A passing smoke is an implementation check, not a result or authorization to scale.

The full grid is computationally larger than the smoke; runtime has not been established. In particular, level fixed effects require repeated matrix decompositions. The original promise of a 1–2 minute run is unverified. Retain logs and code hashes; do not overwrite prior outputs.

Phase B execution: `phaseb_corrected.py --smoke` runs a reduced upstream integration; `--full` uses 20/60/60 seeds per world, 10,000 upstream households, 4,000 women per unit. `--out` must name a new file. Calibration is read from the original synthetic-loop record; each world uses its own chosen nuisance parameters and the common null uses the null calibration. Consequently any classifier separation is conditional on and potentially confounded by nuisance differences; it cannot uniquely identify a mechanism. A matched-nuisance analysis has not been implemented. The null shares one upstream input per seed block across labels but fertility histories are independently drawn per label.

Feature-specific R² gates use the upstream school-utility weights plus GER and child-labor inputs, consistent with the declared gate; an earlier version of this mapping incorrectly described the weights as fertility parameters. A passing gate does not establish causal independence or resolve nuisance confounding. Blocked permutation tests and Holm calculations are exploratory deviations from the original binomial test; null classifier accuracies are descriptive and do not establish a control has passed a formal chance test. The fertility-stratum macro regression, a full formal label-permutation validation of the complete procedure, matched-nuisance follow-up, and DHS transport are not implemented. Smoke test results cannot validate those components.
