# Scientific issue register

Status describes this code revision. Production outcomes await local execution. A missing empirical coefficient remains a missing coefficient even when a sensitivity runner exists.

| Issue | Action in this revision | Remaining work |

Forty-six catalogue entries include tools and downloads, so they are not forty-six independent engines. This register prevents the common runner's presence from being mistaken for a complete scientific audit of every archived implementation.
